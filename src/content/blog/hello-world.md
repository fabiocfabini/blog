Welcome! This is a sample post. To publish a new one, **create a single Markdown
file** in `src/content/blog/` — no other file needs editing. The filename becomes
the URL slug, and the front matter above (title, date, description, tags) drives
everything you see on the page and the blog index.

## Text

Write in plain Markdown: **bold**, _italic_, [links](https://astro.build), lists,
and `inline code`. Headings like the one above show up automatically.

## Images

Reference any image by URL, or drop one in `public/` and link to it:

## Video

Hosted video (e.g. YouTube) embeds with plain HTML right inside Markdown:

<iframe
  width="560"
  height="315"
  src="https://www.youtube.com/embed/aqz-KE-bpKQ"
  title="Video player"
  frameborder="0"
  allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture"
  allowfullscreen></iframe>

That's it. The reading time shown at the top of this page was calculated
automatically from this content — you never type it by hand.
